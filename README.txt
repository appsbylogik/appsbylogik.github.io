AppsByLogik GitHub Pages Website

HOW TO USE:
1. Unzip this folder.
2. Upload the CONTENTS of the folder to a GitHub repository.
   Important: index.html should be in the main/root area of the repo.
3. In GitHub, go to Settings > Pages.
4. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: /root
5. Save. GitHub will create your live website link.

FILES:
- index.html = main website page
- style.css = all design styling
- script.js = mobile menu/dropdown behavior

EDITING APPS:
Open index.html and search for app names like CraftPricer, CraftCommand, BrainJar, CraftStock, and FamMesh. Replace text or add links as needed.

CONTACT EMAIL:
The current email button uses livlogik@gmail.com. You can replace it in index.html if needed.
