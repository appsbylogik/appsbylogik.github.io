- Updated the theme to match your blue/teal AppsByLogik logo.

How to use on GitHub Pages:
1. Unzip this package.
2. Open the appsbylogik-site-v2 folder.
3. Upload the CONTENTS of that folder to your GitHub repository, not the folder itself if you want index.html at root.
4. In GitHub, go to Settings > Pages.
5. Select your main branch and root folder.
6. Save and wait for GitHub to publish the site.

Important:
The policy pages are starter templates. Before using them for Google Play, update each one with the real data practices for that app.
