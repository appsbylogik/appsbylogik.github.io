Data Deletion Request

Users can request deletion of app-related data by contacting AppsByLogik.

How to Request Deletion

  1. Email livlogik@gmail.com.
  2. Use the subject line: Data Deletion Request.
  3. Include the app name and the email/account used in the app.

Requests will be reviewed and handled according to the app’s data storage setup and applicable platform requirements.
